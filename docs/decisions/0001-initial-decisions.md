## 저장소·파일
- 로컬 폴더 이름은 `Book Chronicle`, 문서 파일 이름(`docs/Book Chronicle PRD.md`, `design/design-mockup-*.html`)은 **지금 이름을 유지**합니다. PRD·CLAUDE.md의 `docs/PRD.md`, `design/mockup-*.html`은 이 파일들을 가리킵니다.
- GitHub 저장소: `poguni/book-chronicle` (하이픈 있음). 따라서 GitHub Pages 주소는 `https://poguni.github.io/book-chronicle/`, Vite `base`는 **`/book-chronicle/`**입니다. 코드 식별자(스키마·버킷·함수·백업 파일 이름)는 그대로 `bookchronicle`입니다.
- 커밋·push는 앱 주인이 직접 합니다. Claude는 커밋할 시점과 메시지만 제안합니다.

## 책장·책등 규칙
1. **책등 제목 숨김**: 실제 책등 두께가 14px 미만이면 제목을 숨깁니다(PRD 6.7). 책장 폭을 재서 계산합니다. DESIGN의 "240쪽 미만" 규칙은 쓰지 않습니다.
2. **매핑되지 않은 분야의 기본 패턴**: 라벨형(문서 기준). 시안 코드의 "그 외는 하드커버"는 따르지 않습니다.
3. **책등 높이**: 시안 수치 `(132 + 책 ID 고정 난수 0~41) × --spine-hk`.
4. **한 해가 선반 폭을 넘을 때**: 다음 줄로 넘기고, 줄마다 선반 판을 그립니다.
5. **다시 읽은 책**: 완독 기록 1개 = 책등 1개. 다른 해에 읽었으면 두 해 책장에 모두, 같은 해에 두 번 읽었으면 그해 책장에 두 권으로 꽂습니다.
6. **읽는 중·중단**: 읽는 중인 책은 P1(기대어 놓은 모습) 전까지 책장에 보이지 않고, 중단한 책은 책장에 표시하지 않습니다. "연도 미상" 칸은 완독했지만 완독일이 없는 기록만 맨 아래에 둡니다.
7. **보여 줄 연도**: 올해는 비어 있어도 항상 보이고, 과거의 빈 해는 생략합니다.
8. **직접 입력한 책의 기본 색**: 미리 골라 둔 팔레트 세트에서 책 ID 고정 난수로 하나를 고르고, 사용자가 바꿀 수 있습니다.

## 화면
9. **상세 패널 처음 선택**: 올해 가장 최근에 완독한 책. "2026 한눈에"와 "올해의 나이테"는 올해 고정입니다.
10. **전체 목록**: `#/list` 자리 화면만 먼저 만들고, 기능은 F8(P1)에서 구현합니다.
11. **테마**: 사이드바 세그먼트는 지금 적용된 테마(서재·종이)를 표시하고, 누르면 그 테마로 고정합니다. "시스템 설정 따름"은 설정 화면에서만 고릅니다. 로그인 화면은 마지막 테마를 `localStorage`에 기억해 쓰고, 기록이 없으면 시스템 설정을 따릅니다.
12. **연도 나이테 클릭**: 해시 주소는 바꾸지 않고 그 연도 책장으로 스크롤만 합니다.
13. **별점**: 값이 없으면 `null`(별점 없음)이며, `0`과 구분합니다.
