# 0004. Phase 3 앱 셸·디자인 시스템 결정

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-04 |

## 레이아웃
- **상세 패널은 책장 화면(`#/`)에만 둡니다.** 다른 화면은 사이드바 + 본문 2단입니다. 연말 회고 화면이 상세 패널 자리를 설정 칸으로 쓰는 것(DESIGN 11장)은 Phase 8에서 그 화면 안에 만듭니다.
- 사이드바와 상세 패널은 화면 높이에 붙어 있고(`position: sticky`, 높이 `100dvh`), 내용이 넘치면 각자 안에서 스크롤합니다. 시안은 페이지와 함께 스크롤되지만, 책장이 길어지면 메뉴·계정 영역이 화면 밖으로 밀려나서 바꿨습니다.
- 900~1199px의 닫힌 서랍에는 `visibility: hidden`을 주어, 화면 밖에 있는 버튼에 키보드 포커스가 가지 않게 했습니다.
- 서랍은 책을 누르면 열립니다(Phase 6). 지금은 열 방법이 없고, 닫기 버튼과 Esc 키만 만들어 두었습니다.

## 사이드바
- 연도별 나이테 항목은 링크가 아니라 **버튼**입니다. 주소는 바꾸지 않고 스크롤만 하기 때문입니다(결정 0001-12). 다른 화면에서 누르면 책장 홈으로 이동한 뒤 스크롤합니다.
- 책이 없는 해의 색 띠는 `--bar-off` 바탕만 보입니다.
- "책 한 권 꽂기" 버튼은 아직 아무 일도 하지 않습니다. 대화 상자는 Phase 4에서 만듭니다.
- 900px 미만에서 메뉴를 펼친 뒤 화면을 고르면 메뉴가 저절로 접힙니다.

## 보기 설정(테마·책등 스타일)
- `src/lib/theme.ts`는 순수 함수(`resolveTheme`, 값 읽기)이고, 상태는 `src/lib/prefs.svelte.ts`에 둡니다. 앱을 그리기 전에(`main.ts`) 적용해 테마가 깜빡이지 않게 했습니다.
- **지금은 이 브라우저(`localStorage`)에만 기억합니다.** 키는 `bookchronicle-theme`, `bookchronicle-spine`입니다. `settings` 테이블에 저장해 기기끼리 맞추는 일은 계획대로 Phase 9에서 합니다. 로그인 화면은 결정 0001-11대로 이 값을 씁니다.
- 기본값은 `system`입니다. 운영체제가 어두운 화면이면 서재, 밝은 화면이면 종이를 씁니다. 사이드바에서 고르면 그 테마로 고정됩니다.

## 부품
- 아이콘은 이름으로 고르는 컴포넌트 하나(`Icon.svelte`)로 만들었습니다. 브랜드 나이테만 격자(40px)가 달라 `BrandMark.svelte`로 따로 두었습니다.
- 공통 상태 부품: `EmptyState`(빈 상태), `LoadingSpines`(불러오는 중, Phase 4부터 사용), `OfflineBanner`(연결 끊김 띠, 브라우저의 online·offline 이벤트), `SaveDot`(저장 상태 점, 상태는 `status.svelte.ts`에 있으며 Phase 4부터 데이터 계층이 바꿈).
- 여러 화면에서 쓰는 `.label`, `.btn-primary`, `.page-title`은 `base.css`에 두었습니다. 나머지 스타일은 컴포넌트 안에 있습니다.
- 올해 요약에서 평균 별점은 별점이 하나라도 있을 때만, "작년보다 …권"은 작년 기록이 있을 때만 보여 줍니다.
- "백업 12일 전" 문구는 백업 기능(Phase 7)이 생기면 붙입니다.

## 테스트
- E2E 도우미를 `tests/e2e/helpers.ts`로 옮겼습니다. 900px 미만에서는 메뉴가 접혀 있으므로, 메뉴 안 링크를 누르기 전에 펼칩니다.
- Playwright가 업데이트되어 브라우저를 다시 내려받아야 했습니다(`npx playwright install chromium`).
