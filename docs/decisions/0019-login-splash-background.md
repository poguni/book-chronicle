# 0019. 로그인 화면 배경 그림

- 날짜: 2026-11-06
- 상태: 결정

## 결정

- 로그인 화면 배경에 `public/book-chronicle-splash-screen.webp`(1920×1080, 제목 "북크로니클 / BOOK CHRONICLE"과 책장 그림)를 씁니다. 테마(서재·종이)와 상관없이 같은 그림이고, 카드만 테마 색을 따릅니다.
- 가로 화면은 그림이 화면을 꽉 채우고(cover), 카드는 그림 속 제목 아래(그림 y≈400px)부터 놓습니다.
- 세로 화면은 그림을 위에 붙여 화면 높이의 55%쯤(제목이 잘리지 않게 최대 140vw)으로 키우고, 아래 끝은 바탕색(`--splash-bg`)으로 흐리게 이어 줍니다.
- 그림에 제목과 책장이 있으므로 카드 위의 작은 책장 그림(DESIGN 7.4)은 뺐습니다. 화면 읽기 프로그램을 위해 카드의 "북크로니클 · BOOK CHRONICLE" 라벨은 남깁니다.
