## 설정 저장과 설정 화면
- 테마·책등 스타일은 **Supabase `settings`가 기준**입니다(기기마다 같게). 로그인해 처음 불러올 때 맞추고, 고르면 바로 바꾼 뒤 저장합니다.
  - 첫 동기화: DB가 아직 기본값(시스템·생성형)인데 이 기기에서 고른 값이 있으면 이 기기 값을 DB로 올립니다(예전에 브라우저에만 저장하던 값 보존).
  - 로그인 화면은 계속 이 브라우저에 마지막으로 쓴 테마를 따릅니다(결정 0001-11).
- 움직임 줄이기, 접어 둔 연도는 **기기별**(localStorage)입니다.
- 설정 화면: 보기(테마 3가지, 책등 스타일, 움직임 줄이기), 분야와 책등 무늬, 도서 검색 연결 확인, 백업, 계정(이메일·로그아웃).
  - 분야별 책등 무늬는 기본값과 다른 것만 `pattern_map`에 저장합니다.
  - 분야 이름 바꾸기는 그 분야의 책을 모두 새 이름으로 바꿉니다. 같은 이름의 분야가 있으면 자연히 합쳐집니다. `category_map`은 쓰지 않습니다.

## 표지 질감 모드 (PRD 6.5)
- 표지를 64×256으로 가운데 잘라 흐리게(blur 5px) 만들어 `{user_id}/textures/{book_id}.webp`에 올립니다. 브라우저가 WebP를 못 만들면 PNG로 올립니다(버킷이 PNG 허용).
- 만드는 때: 검색으로 책을 꽂을 때, CSV로 표지를 가져올 때, 표지 질감 모드를 고를 때(질감이 없는 책을 2권씩 한꺼번에, 설정 화면에 진행 막대).
- 책등: 흐린 표지 위에 바탕색을 50% 덧칠하고 그 위에 제목. 질감이 없는 책(표지 없음)은 생성형 책등. 질감 모드에서는 무늬(띠)는 그리지 않고 라벨형 상자만 남습니다.
- **화면에 보이는 책만** 질감 이미지를 내려받습니다(IntersectionObserver, 질감 모드에서만 감시).

## P1 기능
- **지난해 접기**: 올해보다 이전 연도 책장마다 "접기" 버튼과, 위쪽에 "지난해 접기 / 모두 펼치기". 접힌 책장은 그해 책등 색을 쪽수 비율로 이은 띠로 보이고, 띠를 누르면 펼칩니다.
- **강조 보기**: 강조 없음 / 별점 4.5 이상 / 분야(쓰는 분야, 많은 순). 강조하지 않는 책은 흐리게(투명도 0.28, 마우스·초점이 가면 다시 진하게). 접힌 띠에도 적용.
- **읽는 중 기대어 놓기**: 읽는 중 선반의 책을 7° 기울여 기대어 놓은 모습. 꺼내면 바로 섭니다.
- **바코드 스캔**: 책 찾기 칸 오른쪽 바코드 버튼(카메라를 쓸 수 있는 기기에서만). 뒤 카메라로 978·979로 시작하는 EAN-13(검사 숫자 확인)을 읽으면 바로 ISBN 조회.
  - 브라우저 내장 `BarcodeDetector`(안드로이드 크롬 등)를 먼저 쓰고, 없으면(아이폰 사파리 등) `@zxing/browser`를 그때만 불러옵니다(별도 파일 약 120KB gzip).
  - 카메라 권한이 없으면 ISBN을 직접 입력하라고 안내합니다.

## 홈 화면 바로 가기 (PRD F11)
- `public/manifest.webmanifest`(이름 북크로니클, standalone, 서재 색), 아이콘 192·512·마스크 가능 512·apple-touch 180·favicon 32.
- 아이콘은 `public/icons/icon.svg`(나이테 동심원)에서 `node scripts/make-icons.mjs`로 만듭니다(Playwright의 Chromium으로 그림).
- 오프라인 캐시(서비스 워커)는 넣지 않습니다.

## 점검
- **성능**: 책 1,000권(10년치) 가짜 데이터로 로그인부터 모든 책장 표시까지 약 1.1~1.2초(목표 2초). 그 뒤 스크롤 중 50ms 넘는 작업 없음(`tests/e2e/perf.spec.ts`).
  - 가짜 DB가 `offset`·`limit`을 무시해 1,000개씩 나눠 받기가 끝나지 않던 테스트 도구 문제도 고쳤습니다.
- **접근성**: axe(WCAG 2.1 A·AA) 자동 검사(`@axe-core/playwright`, 개발용), 두 테마 × 로그인·책장(꺼낸 책)·연도 비교·연말 회고·가져오기·설정·책 꽂기 대화 상자, 데스크톱·휴대폰 폭 모두 위반 0건(`tests/e2e/a11y.spec.ts`).
- **화면 점검표**: `docs/screen-checklist.md`, `tests/e2e/layout.spec.ts`(`SHOTS=폴더`를 주면 스크린샷도 남김).
- **처음부터 끝까지 E2E**: 로그인 → 검색·등록 → 꺼내 보기·그해의 책 → 연도 비교 → 회고 카드 PNG → JSON 백업(`tests/e2e/journey.spec.ts`).
