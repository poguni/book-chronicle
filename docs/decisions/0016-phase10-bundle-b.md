## 목표 권수 (연도마다)
- **DB**: 마이그레이션 `0006_bookchronicle_reading_goal.sql`로 `bookchronicle.years.reading_goal int null check (1~1000)`을 더했습니다. 기존 RLS("본인 회고만")가 그대로 적용됩니다. 2026-11-05 앱 주인 승인 후 원격에 적용하고 타입을 다시 만들었습니다.
  - Supabase CLI 3.x는 에이전트 실행에서 원격 변경에 `--yes`가 필요합니다. 승인을 받은 뒤에만 붙입니다.
- **정하는 곳**: 책장 위 요약 아래의 "목표 정하기"(고치기·지우기)와 설정 화면의 "목표" 칸. 지금은 **올해 목표만** 화면에서 정합니다. 지난해 목표는 그해에 정해 둔 값이 남아 연도 비교에 보입니다.
  - 숫자 칸은 브라우저 기본 검사 대신(`novalidate`) 앱이 "1에서 1,000 사이의 숫자를 넣어 주세요."로 알립니다.
- **보여 주는 곳**
  - 책장 위 요약: "9 / 15권 · 60%", "6권 남았어요"(이루면 "목표를 이뤘어요!"), 진행 막대(`role="progressbar"`).
  - 상세 패널 "한눈에": 같은 진행률(보기만).
  - 올해의 나이테: 목표가 있으면 나이테를 조금 줄이고 바깥에 진행 호(강조색, 남은 부분은 `--bar-off`), 설명 "목표 15권 중 9권".
  - 연도 비교 권수 카드: 목표가 있는 해에 "목표 15권"(이루면 "목표 15권 달성").
- 진행률 계산은 `goalProgress`(`src/lib/stats.ts`): 막대·호는 100%에서 멈추고, %는 100을 넘어도 그대로 보여 줍니다.
- **백업·복원**: 백업은 `years` 행을 그대로 담으므로 목표도 들어갑니다. 목표가 없던 예전 백업 파일은 목표를 비워(null) 복원합니다.

## 다른 해 책장으로 끌어 옮기기
- 끄는 방법은 결정 0009(내 순서)와 같습니다(마우스·펜만, 6px 넘게 끌면 시작). 끄는 동안 손 아래가 **다른 연도 책장**(접힌 띠 포함)이면 그 책장에 점선 테두리와 "여기에 놓으면 2025년으로 옮겨요"를 보여 주고, 원래 책장의 순서는 처음대로 둡니다.
- 화면 위·아래 끝 72px 안에서는 저절로 스크롤해, 화면 밖 책장에도 놓을 수 있습니다.
- 놓으면 확인 창: 완독일 칸에 **월·일은 그대로, 연도만 바꾼 날짜**를 미리 넣습니다(그해에 없는 2월 29일은 28일). 연도 미상 칸에서 옮기면 오늘의 월·일. 그해 밖의 날짜는 받지 않습니다. 취소·Esc면 아무것도 바꾸지 않습니다.
- 저장: `finished_at`을 바꾸고 `shelf_position`을 비웁니다(새 책장에서 내 순서의 뒤쪽, 완독일순). 연도는 DB 생성 열이 다시 계산합니다.
- 범위: 출발은 연도 책장과 연도 미상 칸, 도착은 화면에 있는 연도 책장. 읽는 중·중단 선반은 상태가 바뀌는 일이라 "기록 수정"으로 합니다. 키보드·휴대폰에서도 "기록 수정"으로 완독일을 바꿉니다.
- 옮긴 책이 원래 해의 그해의 책이었다면, 그해의 책 목록에는 ID가 남지만 그해 책장에 없으므로 보이지 않습니다(다시 옮겨 오면 되살아남).
- 계산은 `src/lib/moveYear.ts`(`movedDate`, `dateInYear`), 창은 `MoveDateDialog.svelte`.

## 테스트
- 단위: `goalProgress`, `movedDate`·`dateInYear`, 예전 백업 복원(목표 null) — 188개.
