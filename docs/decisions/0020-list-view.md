# 0020. 전체 목록 화면

- 날짜: 2026-11-06
- 상태: 결정

## 결정

- **한 줄 = 독서 기록 하나**: 연도·별점은 기록마다 다르므로 기록 단위로 보여 줍니다. 다시 읽은 기록에는 "2회째" 표시를 붙이고, "다시 읽은 책만"을 켜면 두 번 이상 완독한 책의 기록을 읽은 순서로 붙여 보여 줍니다(묶음은 고른 정렬에서 그 책이 처음 나온 자리). 읽는 중·중단 기록도 목록에 넣고 연도 거르기로 고를 수 있습니다.
- **검색**: 내 책장 안에서 제목·저자를 찾습니다. 대소문자와 띄어쓰기를 가리지 않습니다("해리포터" = "해리 포터").
- **정렬**: 최근에 읽은 순(기본) / 오래된 순 / 제목 가나다순 / 별점 높은 순 / 두꺼운 순. 완독일·별점·쪽수가 없는 기록은 끝에 둡니다.
- **거르기 상태**: 다른 메뉴에 다녀와도 그대로 둡니다(모듈 상태). 새로 고침하면 처음 상태로 돌아갑니다. 주소에는 담지 않습니다.
- **상세 패널**: 책장과 같은 상세 패널을 목록 화면에도 둡니다. 줄을 누르면 그 기록이 선택되고, 다시 누르면 선택을 풉니다.
- **성능**: 처음에는 100줄만 그리고 "더 보기"로 100줄씩 늘립니다.
- **배치**: 목록 폭이 640px 이상이면 표(제목·저자·분야·완독·별점·쪽수), 좁으면 두 줄 카드(제목 / 저자 · 완독 · 별점)입니다(컨테이너 쿼리). 검색·거르기 줄은 900px 이상에서만 위에 고정합니다(스마트폰은 화면을 너무 가림).
