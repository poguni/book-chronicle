# 0005. Phase 4 책 입력과 생성형 책등 결정

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-04 |

## 데이터
- 책장 데이터는 `src/lib/library.svelte.ts` 한곳에서 들고 있습니다. 컴포넌트는 이 저장소와 `src/lib/data/`만 거칩니다.
- 저장한 뒤에는 네 테이블(books·readings·years·settings)을 **다시 불러옵니다.** 기본값(user_id, 생성 시각, `readings.year`)을 DB가 정하므로 화면과 DB가 어긋나지 않게 하려는 것입니다. 1,000권이 넘으면 나눠 받습니다(`fetchAll`). 성능은 Phase 9에서 1,000권 데이터로 확인합니다.
- 새 책의 ID는 브라우저에서 미리 만듭니다(`crypto.randomUUID()`). 그 ID로 기본 색 세트를 골라 미리 보기와 저장 결과가 같게 합니다(결정 0001-8).
- 책을 넣은 뒤 첫 기록 넣기가 실패하면 책을 지워 되돌립니다(기록 없는 책이 남지 않게).
- 기록 지우기: 그 책의 기록이 하나뿐이면 **책까지** 지우고(표지·질감 파일도), 여러 개면 그 기록만 지웁니다. 버튼 이름도 "이 책 지우기"·"이 기록만 지우기"로 달리 보여 줍니다.
- `spine.manual`은 사용자가 색을 직접 바꿨을 때만 `true`가 됩니다. Phase 5에서 표지 색을 다시 뽑을 때 이 값을 보고 덮어쓰지 않습니다.
- 저장 실패는 대화 상자 안에 알리고, 입력 내용은 그대로 둡니다. 다시 누르면 다시 시도합니다(DESIGN 12장의 "화면 아래 알림 띠" 대신. 대화 상자가 열려 있는 동안에는 그 안이 더 잘 보여서). 계정 영역 점도 강조색으로 바뀝니다.

## 책등
- 계산은 순수 함수로 나눴습니다: `spine/patterns.ts`(분야 → 패턴), `spine/color.ts`(글자색·색상순), `spine/geometry.ts`(두께·높이·줄 나눔·쪽수 추정), `spine/spineData.ts`(jsonb 읽기, 기본 색 세트), `shelves.ts`(연도별 책장), `stats.ts`(요약·월별·나이테).
- **글자색은 명암비로 고릅니다**(PRD 6.7). 밝은 글자(`#FBF7EF`)와 어두운 글자(`#1F1A16`) 중 바탕과 명암비가 높은 쪽입니다. DESIGN 6.3의 "휘도 0.36 기준"과 거의 같은 결과입니다.
- 기본 패턴 매핑의 열쇠는 알라딘 2단계 분야 이름(`소설/시/희곡`, `인문학`, `사회과학` 등)과 짧은 이름(`소설`, `인문`, `사회`)을 함께 둡니다. "외서 " 표시는 떼고 찾습니다.
- 제목 숨김(두께 14px 미만)과 줄 나눔은 책장 안쪽 폭을 `ResizeObserver`로 재서 CSS와 같은 식으로 계산합니다.
- 시안은 저자 이름을 책등 아래에 절대 위치로 두는데, 짧은 책등(화면 폭 1028px 이하)에서 제목과 겹칩니다. 그래서 **저자를 흐름 안에 두고 제목이 줄어들며 말줄임표로 끝나게** 바꿨습니다.
- 판형(`books.size`)으로 두께·높이 정하기(PRD 6.1·6.2)는 알라딘에서 판형을 받아 오는 Phase 5 이후에 붙입니다. 지금은 쪽수와 책 ID 고정 난수만 씁니다.
- 표지 질감 모드는 질감 이미지가 생기는 Phase 9 전까지 생성형 책등으로 그립니다(PRD 6.5 "표지가 없으면 생성형으로 대체").

## 화면
- **꺼내 보기(Phase 6) 전까지는 책등을 누르면 기록 고치기 대화 상자가 열립니다.** 키보드 ←→ 이동은 지금 넣었습니다.
- 대화 상자는 `<dialog>`(showModal)라 Esc로 닫히고 포커스가 안에 머뭅니다. 화면 폭 760px 이하에서는 전체 화면입니다.
- 별점은 고르기 상자(별점 없음, 5~0점, 0.5 단위)로 받습니다. 별 모양 입력은 상세 패널(Phase 6)에서 다시 봅니다.
- 상태(완독·읽는 중·중단)도 대화 상자에서 고릅니다(PRD F1). 읽는 중·중단 기록은 책장에 꽂히지 않습니다(결정 0001-6).
- 정렬 칩(완독일순·색상순·분야순)은 동작합니다. 검색창은 F8(P1)에서 붙입니다.
- 상세 패널의 "2026 한눈에"(권수·쪽수·평균 별점·가장 많이 읽은 분야·월별 막대)도 함께 이었습니다. 월별 막대는 시안처럼 한 권에 26px이되, 많이 읽은 달이 칸을 넘지 않게 줄입니다.
- 쪽수 합계에는 쪽수를 아는 책만 더합니다(추정한 쪽수는 두께에만 씀).
