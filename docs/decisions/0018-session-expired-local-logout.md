# 0018. 서버에서 끝난 로그인 처리와 이 브라우저만 로그아웃

- 날짜: 2026-11-06
- 상태: 결정

## 배경
기존 독서 앱에서 같은 계정으로 로그아웃하자(Supabase 기본값 `scope: 'global'`) 북크로니클의 세션도 서버에서 지워졌습니다.
브라우저의 access token은 만료 전까지 서명만으로 통과해 책장은 보였지만, 도서 검색 함수는 `auth.getUser`로 Auth 서버에 묻기 때문에 `session_not_found` → 401이 났고, 앱은 이를 "이 계정으로는 도서 검색을 쓸 수 없어요"(권한 없음)로 잘못 안내했습니다.

## 결정
1. 도서 정보 함수가 401을 주면 `refreshSession()`을 한 번 해 보고 새 토큰으로 다시 부릅니다. 새로 받지 못하거나 새 토큰도 401이면 이 브라우저의 세션을 지우고 로그인 화면에 "로그인이 끝났어요. 다시 로그인해 주세요"를 보여 줍니다(`BookApiError` 종류 `expired`). 403(앱 주인 아님)은 지금처럼 `denied`입니다.
2. 북크로니클의 로그아웃은 `signOut({ scope: 'local' })`로 이 브라우저만 끊습니다. 기존 독서 앱과 다른 기기의 로그인은 그대로 둡니다. 기존 앱의 로그아웃 방식은 공유 규칙상 바꾸지 않으므로, 기존 앱에서 로그아웃하면 북크로니클도 다시 로그인해야 합니다.
