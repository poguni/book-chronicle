# 0007. Phase 5 알라딘 검색과 표지 결정

| 항목 | 내용 |

## Edge Function `bookchronicle-aladin`
- **로그인 확인은 함수 안에서** 합니다. 이 프로젝트는 publishable 키(`sb_publishable_...`)를 쓰는데, 플랫폼의 `verify_jwt`는 예전 JWT 키만 이해합니다(Supabase 문서). 그래서 `verify_jwt = false`(`supabase/config.toml`, 배포 때 `--no-verify-jwt`)로 두고, 함수가 Auth 서버에 토큰을 물어(`auth.getUser`) 사용자를 확인한 뒤 `BOOKCHRONICLE_OWNER_ID`와 같을 때만 처리합니다. 토큰이 없거나 틀리면 401, 다른 가입자는 403입니다.
- 허용한 주소(`https://poguni.github.io`, `localhost`·`127.0.0.1`의 5173·4173)에서 온 요청에만 CORS 헤더를 붙이고, 다른 Origin은 403으로 거절합니다.
- 요청: `search`(ItemSearch, 최대 20건, 국내도서), `lookup`(ItemLookUp, ISBN-13, `OptResult=packing`으로 판형도 받음), `cover`(표지 중계).
- 검색·조회 결과는 `bookchronicle.aladin_cache`에 24시간 캐시합니다. 이 표는 RLS 정책이 없어 함수가 비밀 키(`SUPABASE_SECRET_KEYS`, 없으면 예전 `SUPABASE_SERVICE_ROLE_KEY`)로만 읽고 씁니다.
- TTB 키는 함수 안에서만 씁니다. 알라딘 요청 주소에 키가 들어가므로, 네트워크 오류 메시지를 그대로 내보내지 않고 짧은 코드(`aladin_unreachable`, `aladin_10` 등)만 돌려줍니다.
- 핵심 로직은 `handler.ts`로 나눠 Deno 전용 API 없이 썼습니다. 이 PC에 Deno·Docker가 없어 `supabase functions serve`를 못 쓰므로, Vitest로 알라딘·로그인·캐시를 흉내 내 검사합니다(`tests/unit/aladinFunction.test.ts`). 배포 뒤에는 `npm run check:aladin`으로 원격에서 확인합니다.

## 표지: `importCover` 대신 `cover` 중계 (PRD 5.6을 바꿈)
- PRD는 함수가 표지를 받아 300px로 줄여 Storage에 올리도록(`importCover`) 했습니다. 대신 **함수는 알라딘 이미지만 중계**하고, 브라우저가 줄이고 올립니다.
  - 색 뽑기(PRD 6.3)를 하려면 어차피 브라우저가 표지 픽셀을 읽어야 하고, 알라딘 이미지는 CORS 때문에 캔버스로 직접 못 읽습니다.
  - Deno에서 이미지를 풀고 줄이려면 라이브러리와 CPU 시간이 더 듭니다.
  - 고른 책을 저장하지 않고 대화 상자를 닫으면 Storage에 파일이 남지 않습니다(저장할 때만 올림).
- 중계는 `image.aladin.co.kr`만, https로, 다른 곳으로 넘겨 보내기(redirect)는 따르지 않고, 이미지 형식·2MB 이하만 받습니다.
- 브라우저의 Web Worker(`src/workers/palette.worker.ts`)가 64×64로 줄여 팔레트를 뽑고, 가로 300px 이하 JPEG로 다시 만듭니다. 저장할 때 `{user_id}/covers/{book_id}.jpg`에 올리고(RLS: 본인 폴더만), 책을 넣지 못하면 방금 올린 파일을 지웁니다.
- 표지 보여 주기는 `src/lib/covers.svelte.ts`: Storage에서 Blob으로 받아 화면 주소로 쓰고, 탭 안에서 한 번만 받습니다. 로그아웃하면 비웁니다. 책장 책등의 표지 면에 붙이는 일은 Phase 6(꺼내 보기)에서 합니다.

## 앱
- 책 꽂기 대화 상자 맨 위에 검색(제목·저자·ISBN, 300ms 기다렸다가 찾기, Enter는 바로 찾기, 최근 검색어 5개). 하이픈이 있어도 ISBN-10·13이면 바로 상품 조회합니다.
- 검색 결과를 고르면 상품 조회로 쪽수·판형을 보충하고 칸을 채웁니다. 제목은 " - " 뒤 부제를 떼고, 저자는 지은이만 남깁니다(옮긴이·감수 등은 뺌). 모든 값은 고칠 수 있습니다.
- **분야**: 알라딘 분야 경로의 낱말로 24개 분야(결정 0006) 중 하나를 고르고, 맞는 것이 없으면 2단계 이름을 직접 입력값으로 둡니다(외국도서는 "외서 "를 붙임). 원래 경로는 `category_raw`에 저장합니다.
- **이미 책장에 있는 ISBN**을 고르면(ISBN은 사용자마다 하나) 새 책 대신 그 책의 "다시 읽은 기록 더하기"로 바꾸고 알려 줍니다.
- 책등 색: 세 칸(바탕·띠·강조) 중 하나를 고르고, 표지에서 뽑은 후보 5색이나 "색 직접 고르기"로 넣습니다. 사용자가 색을 바꾸면 `spine.manual = true`.
- 책등 미리 보기 양옆에 올해 책장 끝의 두 권을 세워 "앞뒤 책 사이에 꽂힌 모습"을 보여 줍니다.
- 시간 제한 8초, 연결·서버 문제면 한 번 더 시도합니다. 로그인·권한(401·403)과 잘못된 요청(400)은 다시 하지 않습니다.
- 오류 문구: "검색이 잠시 안 돼요. 직접 입력할 수 있어요." / 앱 주인이 아닌 계정: "이 계정으로는 도서 검색을 쓸 수 없어요. 직접 입력할 수 있어요."
- "도서 DB 제공: 알라딘 인터넷서점"은 사이드바와 검색 상자 아래에 둡니다.
- 판형으로 책등 두께·높이 정하기(PRD 6.1·6.2)는 아직 하지 않습니다. 판형은 저장만 해 두었습니다.
- 바코드 스캔(P1)과 기존 책의 표지 다시 가져오기는 하지 않았습니다.
