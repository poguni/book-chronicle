## 1. 개요

| 항목 | 내용 |

| 한 줄 소개 | 해마다 읽은 책을 책등이 꽂힌 책장으로 보여 주는 개인용 독서 연대기 웹 앱 |
| 대상 사용자 | 앱 주인 1명. 데스크톱 브라우저에서 기록하고, 스마트폰에서 로그인해 같은 책장을 확인 |

## 2. 목표 및 배경

- 엑셀이나 다른 앱에 흩어진 독서 기록을 **한눈에 보이는 책장**으로 바꾸는 것이 출발점입니다. 한 해가 한 선반이고, 쪽수가 두께, 분야가 책등 무늬, 표지 색이 책등 색이 됩니다.
- 핵심 가치
  - **보는 즐거움**: 숫자 목록 대신 실제 책장처럼 꽂힌 책등, 꺼내 보는 3D 움직임, 연도별 나이테.
  - **빠른 기록**: ISBN·제목 검색으로 책 한 권 등록을 10초 안에.
  - **첫날부터 여러 해**: 기존 기록을 CSV로 가져와 바로 여러 해의 책장을 채움.
  - **돌아보기**: 연도끼리 비교하고, 연말에 그해의 책·한 줄 회고·공유용 회고 카드를 만듦.
  - **이어 가기**(v2): 올해 목표 권수를 정하고 책장·나이테에서 진행률을 확인.
- 운영 제약: 새 서비스를 늘리지 않고 **GitHub(Pages)와 Supabase 무료 요금제** 안에서 운영합니다. Supabase 프로젝트는 기존 독서 앱과 함께 쓰므로 `bookchronicle` 스키마만 다룹니다.
- 하지 않는 것: 오프라인 사용, 여러 사용자·소셜 기능, 기존 앱과의 데이터 교환, 인용문·독서 노트 중심 기능(P2), AI 추천.

## 3. 주요 기능

### 책장 홈 (`#/`)
- 연도별 책장(올해는 비어 있어도 표시), 맨 위 "읽는 중" 선반, 맨 아래 "중단한 책"·"연도 미상" 선반.
- 생성형 책등: 쪽수 → 두께, 분야 → 무늬(하드커버·페이퍼백·라벨형), 표지 → 색, 제목은 말줄임 없이 모두 표시(Pretendard).
- 표지 질감 모드: 흐린 표지를 깐 책등(표지가 없는 책은 생성형).
- 정렬 6가지: 내 순서(끌어 옮기기, Alt+←→), 완독일순, 색상순, 분야순, 별점순, 쪽수순.
- **다른 해 책장으로 끌어 옮기기**(v2): 마우스로 다른 해 책장에 놓으면 완독일 확인 창(월·일 유지, 연도만 바꿔 미리 채움). 화면 끝에서 자동 스크롤.
- 꺼내 보기: 책등을 누르면 3D로 돌아 나오며 표지 면이 보이고, 오른쪽 상세 패널에 표지·별점·메모·독서 기록.
- 강조 보기(별점 4.5 이상 또는 분야), 지난해 접기(책등 색 띠), 읽는 중 책 기대어 놓기.
- 올해 요약, "한눈에", 올해의 나이테(연도별 동심원).
- **목표 권수**(v2): 요약 아래 "9 / 15권 · 60% · 6권 남았어요"와 진행 막대, 나이테 바깥 진행 호. 연도마다 저장.

### 책 꽂기
- 카카오 책 검색(제목·저자) + 국립중앙도서관 ISBN 서지정보(쪽수·KDC 분류) 자동 입력.
- **검색 함수 미리 깨우기**(v2): 책 찾기 칸에 처음 입력할 때 함수를 미리 깨워 첫 검색의 콜드 스타트를 줄임.
- 표지에서 책등 색 3가지(바탕·띠·강조) 추출, 직접 바꾸기 가능.
- 바코드 스캔(휴대폰 카메라로 ISBN).
- 별 5개를 눌러 채우는 0.5 단위 별점, 분야 24개 + 직접 입력, 수동 입력 전환.

### 가져오기·백업 (`#/import`)
- CSV 가져오기: 인코딩 자동 판별(UTF-8/CP949), 열 맞추기 추천, 다양한 날짜·별점 형식, Goodreads 형식 인식, 보충 조회(동시 2건), 중복 처리(건너뛰기·기록만 추가·덮어쓰기).
- JSON 백업·복원(덮어쓰기/합치기, 표지 포함 선택), CSV 내보내기(UTF-8 BOM), 30일 백업 알림. 백업에 목표 권수 포함(v2).

### 연도 비교 (`#/compare`)
- 2~5개 연도의 지표 카드 6개(권수·총 쪽수·평균 쪽수·평균 별점·가장 두꺼운 책·최다 분야)와 증감. 권수 카드에 목표·달성 표시(v2).
- 월별 선 그래프(권수·쪽수, 누적), 분야 비중 100% 누적 막대, 표로 보기.
- **연도별 추이**(v2): 책이 있는 첫해~올해의 권수·쪽수 막대(빈 해는 0, 비교 중인 연도는 진하게).

### 연말 회고 (`#/recap/2026`)
- **그해의 책 1~3위**(v2): 고른 순서가 순위, 순위 올리기·내리기·빼기, 아직 고르지 않은 책 중 별점 기반 후보 제안. 한 줄 회고(80자), 12월 안내.
- 회고 카드: **템플릿 3가지**(v2: 책장형·월별형·분야형), 크기 3가지(정사각·세로·스토리), 테마 3가지(서재·종이·책등 색), 항목 선택, PNG 저장·공유. 2·3위는 1위 아래에 작게.

### 설정 (`#/settings`)
- 테마(기기 설정·서재·종이)·책등 스타일(계정에 저장), 움직임 줄이기(기기별).
- **올해 목표 권수** 정하기·고치기·지우기(v2).
- 분야별 책등 무늬, 분야 이름 바꾸기·합치기, 도서 검색 연결 확인, 백업 바로 가기, 계정·로그아웃.

### 기타
- 이메일 + 비밀번호 로그인(회원 가입 화면 없음), 홈 화면 바로 가기(웹 앱 매니페스트·나이테 아이콘).

## 4. 기술 스택 및 아키텍처

| 구분 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | Svelte 5(runes) + TypeScript 6.0 + Vite 8 | 작은 번들, 반응형 상태가 단순함. TS는 `typescript-eslint` 지원 범위 때문에 6.0 |
| 라우팅 | 직접 만든 해시 라우터 | 화면이 7개뿐이고 GitHub Pages는 서버 라우팅이 없음 |
| 백엔드 | Supabase(Auth·Postgres·Storage·Edge Functions) | 이미 쓰는 무료 프로젝트. `bookchronicle` 스키마로 분리 |
| 도서 정보 | 카카오 책 검색 + 국립중앙도서관 ISBN 서지정보 | 알라딘 Open API가 2026-10-30에 종료(결정 0008) |
| 그래프 | Chart.js(연도 비교 화면에서만 지연 로드, 약 57KB gzip) | 구현 계획에 정한 라이브러리 |
| 회고 카드 | Canvas 2D(직접 그림) | 템플릿·크기·테마 조합을 한 함수로 그리고 PNG로 저장 |
| CSV | Papa Parse | 따옴표·줄바꿈이 섞인 CSV를 안정적으로 읽음 |
| 바코드 | `BarcodeDetector` → 없으면 ZXing(스캔할 때만 로드, 약 120KB gzip) | 아이폰 사파리에는 내장 인식기가 없음 |
| 배포 | GitHub Actions → GitHub Pages | `main`에 올리면 자동 배포 |
| 테스트 | Vitest(단위), Playwright(E2E), axe-core(접근성) | 계산은 단위 테스트, 화면 흐름은 가짜 Supabase로 E2E |

### 구조

```
브라우저 (Svelte SPA, GitHub Pages)
 ├─ src/pages/       화면: Login, Shelves, Compare, Recap, Import, Settings, List
 ├─ src/components/  부품: Shelf, Book, DetailPanel, BookDialog, BookSearch,
 │                         GoalProgress, MoveDateDialog, ...
 ├─ src/lib/         순수 계산(spine/, shelves, stats, csv, backup, recapCard,
 │                         bookOfYear, moveYear ...)
 │                   상태 저장소(library.svelte.ts, prefs.svelte.ts, auth.svelte.ts)
 └─ src/lib/data/    Supabase 접근은 여기서만 (books, readings, years, settings, covers)
          │  publishable 키 + 로그인 세션
          ▼
Supabase (공유 프로젝트, bookchronicle 스키마만)
 ├─ 테이블: books, readings, years, settings, aladin_cache  (모두 RLS "본인 행만")
 ├─ Storage: bookchronicle-covers (비공개, 표지·질감)
 └─ Edge Function: bookchronicle-books  ──▶ 카카오 / 국립중앙도서관 (API 키는 secrets에만)
```

- **데이터 모델**: `books`(책 정보·책등 팔레트·표지 경로) 1 : N `readings`(독서 기록, 완독 1회 = 책등 1개). `readings.year`는 완독일에서 계산하는 생성 열. `years`(그해의 책 1~3위 배열·한 줄 회고·**목표 권수 `reading_goal`**), `settings`(테마·책등 스타일·무늬 매핑).
- **마이그레이션**: `0001`~`0006`. v2에서 `0006_bookchronicle_reading_goal.sql`(목표 권수 열)을 더했습니다.
- **상태 관리**: 책장 데이터는 `library.svelte.ts` 한곳에 두고, 저장 후에는 네 테이블을 다시 불러와 화면과 DB가 어긋나지 않게 합니다.
- **스타일**: 색·글꼴·간격은 `tokens.css`·`themes.css`의 CSS 변수만 씁니다. 테마는 `<html data-theme>`, 책등 스타일은 `data-spine`, 움직임 줄이기는 `data-motion`.

## 6. 주요 의사결정과 이유

| 결정 | 이유 |
|---|---|
| **알라딘 → 카카오 + 국립중앙도서관** (0008) | Phase 5 배포 후 알라딘이 "OpenAPI 서비스 종료"를 돌려줌. 카카오는 검색·표지, 국립중앙도서관은 쪽수·KDC 분류를 맡고, 키가 없으면 카카오 정보만으로도 동작 |
| **Edge Function이 직접 로그인 확인** (`verify_jwt=false`, 0007) | publishable 키는 플랫폼 `verify_jwt`가 이해하지 못함. 함수 안에서 `auth.getUser`로 확인하고 앱 주인 ID만 허용(회원 가입이 열려 있는 공유 프로젝트이므로) |
| **표지는 함수가 중계, 브라우저가 줄이고 올림** (0007) | 색 추출에는 어차피 브라우저가 픽셀을 읽어야 하고, 외부 이미지는 CORS 때문에 캔버스로 못 읽음 |
| **`readings.year` 생성 열, 외래 키 `(book_id, user_id)`** (0003) | 완독일과 연도가 어긋날 수 없게, 남의 책 ID에 기록을 달 수 없게(외래 키 검사는 RLS를 거치지 않음) |
| **세션 저장 이름 `bookchronicle-auth`, localStorage** (0003) | 같은 도메인의 다른 앱과 세션이 섞이지 않고, 기기마다 한 번만 로그인 |
| **읽는 중·중단 선반을 따로** (0006) | 상태를 바꾸면 책이 사라져 보인다는 앱 주인 의견 |
| **책등 제목을 숨기지 않고 모두 표시** (0009) | "작아도 제목이 다 보이면 좋겠다"는 요청. `fitTitle`이 12→7px 글자 크기와 세로 줄 수를 고름. 작은 크기에 강한 Pretendard 채택 |
| **얇은 책등** (0009) | 한 해 15권이 보기 좋게: `clamp(12px, max(p×0.012cqw, p×0.07px), max(6cqw,36px))` |
| **끌어 옮기기는 마우스·펜만, 터치 끌기 없음** (0009·0016) | 휴대폰에서는 스크롤과 겹치고, 휴대폰은 확인용. 휴대폰·키보드는 "기록 수정"으로 같은 일을 함 |
| **제목 글꼴 고운 돋움** (0010) | 앱 주인 요청. 굵기가 400 하나라 크기·색으로 위계를 나눔 |
| **연도 색은 순위가 아니라 연도를 따라감** (0013) | 비교할 연도를 바꿔도 색이 바뀌지 않게. 색약 배려로 선 모양·점 모양도 다르게, 표로 보기 항상 제공 |
| **테마·책등은 계정, 움직임 줄이기·접은 연도는 기기별** (0014) | 데스크톱에서 고른 보기가 휴대폰에도 같게, 기기 성격에 따른 설정은 기기마다 |
| **미리 깨우기는 OPTIONS 요청으로** (0015) | 함수가 로그인 확인·외부 API 호출 없이 204로 답하는 요청이라 함수 재배포가 필요 없고 카카오·국립중앙도서관 한도도 쓰지 않음. 대화 상자를 열기만 해서는 보내지 않음 |
| **연도별 추이는 강조색 한 가지** (0015) | 값이 하나뿐이라 연도 색(`--series-*`)을 쓰면 "색 = 연도" 약속과 겹침. 비교 중인 연도는 진하게, 나머지는 옅게 |
| **그해의 책 순위 = 배열 순서** (0015) | DB에 이미 `book_of_year uuid[]`(최대 3개 검사)가 있어 스키마를 바꾸지 않고 순위를 표현 |
| **회고 카드는 템플릿을 따로 고르기** (0015) | 앱 주인 선택. 가운데 그림 자리만 바꾸고 배치 높이는 같아 기존 배치 검사가 그대로 통함. 막대는 카드 강조색 한 가지(책등 색 테마의 바탕 대비 때문) |
| **목표 권수는 연도마다** (0016) | 앱 주인 선택. `years.reading_goal`에 두어 해마다 목표가 남고, 연도 비교에서 달성 여부를 볼 수 있음 |
| **다른 해로 옮길 때 날짜 칸을 채워 확인** (0016) | 앱 주인 선택. 월·일을 그대로 두고 연도만 바꿔 미리 넣고, 그해 밖의 날짜는 받지 않음 |
| **오프라인 캐시(서비스 워커) 없음** | 데이터 원본은 Supabase 하나. 오래된 캐시로 기기 간 내용이 어긋나는 일을 피함 |
| **`main`에 바로 커밋** (2026-11-04) | 1인 프로젝트. 대신 커밋 전 검사 종료 코드 0을 꼭 확인 |

## 8. 보안/성능 고려사항

### 보안
- 공유 Supabase 프로젝트: `bookchronicle` 스키마·`bookchronicle-covers` 버킷·`bookchronicle-` 함수만 다루고, 기존 앱 자원(`public.books` 등)은 읽지도 고치지도 않음.
- 모든 테이블·버킷에 RLS "본인 행만"(`user_id = (select auth.uid())`). `anon` 권한 회수. `storage.objects` 정책은 이름에 접두사를 붙이고 `bucket_id`로 한정. `npm run check:rls`로 원격 점검. v2의 새 열(`years.reading_goal`)에도 기존 정책이 그대로 적용됨.
- 브라우저에는 Supabase 주소와 publishable 키만. 카카오 REST 키·국립중앙도서관 인증키는 `supabase secrets`에만 두고, 오류 메시지에도 키가 섞이지 않게 짧은 코드만 돌려줌.
- Edge Function: 허용한 Origin에만 CORS, 로그인 + 앱 주인 ID 확인(401/403). 미리 깨우기 요청(OPTIONS)은 데이터 없이 204만 돌려줌.
- GitHub 저장소: Secret Protection과 Push protection을 켬(2026-11-05). 형식이 정해지지 않은 도서 API 키는 걸러지지 않을 수 있어, 키는 계속 secrets에만 둠.
- Auth 설정(사이트 주소, 회원 가입 허용, 메일 템플릿)은 기존 앱에 영향을 주므로 바꾸지 않음.
- 원격 DB 적용·함수 배포·비밀 값 등록은 매번 앱 주인 확인 후 실행(v2의 0006도 미리 보기 결과를 보여 드린 뒤 승인받아 적용).

### 성능
- 책 1,000권(10년치)에서 로그인 → 모든 책장 표시 약 1.1~1.2초(목표 2초), 스크롤 중 50ms 넘는 작업 없음.
- 무거운 라이브러리는 필요한 화면에서만 지연 로드(Chart.js, ZXing).
- 표지는 꺼냈을 때, 질감은 화면에 보일 때만 내려받음. 질감 이미지는 64×256 WebP.
- 1,000행이 넘는 테이블은 나눠 받기(`fetchAll`), CSV 저장은 100건씩.
- 검색 함수는 5분에 한 번까지만 미리 깨움.

## 10. 배포

- `main`에 푸시하면 GitHub Actions가 빌드(`vite build`, `base: '/book-chronicle/'`)해 GitHub Pages로 배포합니다.
- 주소: **https://poguni.github.io/book-chronicle/** (해시 주소: `#/`, `#/compare`, `#/recap/2026`, `#/import`, `#/settings`)
- DB: `supabase/migrations/0001~0006`을 `npx supabase db push --remote`로 적용(앱 주인 승인 후). 에이전트로 실행할 때는 승인 뒤 `--yes`를 붙입니다.

## 11. 알려진 한계

- **국립중앙도서관 인증키 승인 대기**: 그전까지 검색으로 꽂은 책은 쪽수가 비어 분야 평균으로 추정해 그립니다.
- **실기기 확인이 남음**: 바코드 스캔, 홈 화면 추가, 표지 질감 모드, 회고 카드 공유·사진첩 저장, 실제 200행 CSV 가져오기 시간, 미리 깨우기로 첫 검색이 빨라졌는지는 아직 기록하지 못했습니다.
- **오프라인 사용 불가**(의도한 범위).
- **휴대폰·키보드로는 끌어 옮기기 불가**: 순서 바꾸기는 키보드 Alt+←→가 있지만, 다른 해로 옮기기는 "기록 수정"으로만 합니다.
- **화면에 없는 해로는 끌어 옮길 수 없음**: 책이 없는 지난해는 책장이 없으므로 "기록 수정"으로 날짜를 바꿉니다.
- **지난해 목표는 화면에서 정할 수 없음**: 목표는 올해만 정하고, 해마다 그때 정한 값이 남습니다.
- **그해의 책을 다른 해로 옮기면**: 원래 해의 목록에 ID는 남지만 보이지 않습니다(다시 옮겨 오면 되살아남).
- **판형(책 크기) 없음**: 두 도서 API 모두 mm 판형을 주지 않아 책등 높이는 책 ID 기반 난수입니다.
- **로컬 DB·Edge Function 실행 환경 없음**: 이 PC에 Docker·Deno가 없어 마이그레이션은 원격에서 바로, 함수는 Vitest 흉내와 배포 후 점검으로 확인합니다.
- **종이 테마 그래프 색 대비**: 일부 연도 색이 흰 바탕과 3:1 미만이라 범례·표로 보기에 기댑니다.
- **문서 불일치**: PRD 6.7·DESIGN 6.2의 "14px 미만이면 제목 숨김", 설정 저장 범위, 정렬 칩·강조·접기 조작부, 그해의 책 3권·목표 권수·카드 템플릿이 결정 기록(0009~0016)과 다르거나 빠져 있습니다(결정 기록이 우선).

- **회고 카드 템플릿 더하기**: 목표 달성 카드(진행 호 + 권수), 별점 분포 카드.
- **키보드로 다른 해로 옮기기**: 책등에서 단축키로 옮기기 창을 열어 마우스 없이도 같은 일을 하기.
- **연도 비교에 목표 달성률 그래프**: 해마다 목표 대비 몇 %를 읽었는지.

### 아이디어 수준
- **인용문·독서 노트(P2)**: 책마다 밑줄 친 문장을 모아 보는 공책.
- **시리즈 묶기**: 같은 시리즈 책등을 이어 붙여 보여 주기.
- **책등 직접 꾸미기**: 무늬·글꼴·띠 위치를 책마다 고르기.
- **연도 타임랩스**: 해마다 책장이 채워지는 모습을 애니메이션으로.
